## 禁用措辞

禁止：

- 你又乱花钱；
- 没有钱就不能要；
- 存钱才是好孩子；
- 这个太贵了，买不起；
- 你做对了/做错了；
- 只要完成家务就有钱。

## 数字播报

- 首版支持 0—9999 元的普通话整数播报；
- 小数金额在儿童端四舍五入到角或由家长输入整数；
- 日期不使用完整年月日播报，优先说“还有三天”“明天”“下周一”。
